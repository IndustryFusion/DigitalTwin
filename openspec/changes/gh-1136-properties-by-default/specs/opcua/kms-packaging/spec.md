## ADDED Requirements

### Requirement: The package check covers OPC UA Properties
`make kms-packages-check` SHALL fail, naming the package, when the shapes of the generated `opcua-pumps` do not constrain `opcua:hasEngineeringUnits` under the analog variable `pumps:hasMotorTemperature` of `pumps:DriveMeasurementsType`. The package SHALL still pass `semforge verify` and `semforge validate` with the Properties it holds.

#### Scenario: Pump package with units
- **WHEN** the example packages are generated by `make kms-packages` and checked by `make kms-packages-check`
- **THEN** the check passes, and `opcua-pumps` passes `semforge verify` and `semforge validate`

#### Scenario: Pump package without units
- **WHEN** `make kms-packages-check` runs on an `opcua-pumps` built with `--no-properties`
- **THEN** it fails and names `opcua-pumps` and the missing `opcua:hasEngineeringUnits`
